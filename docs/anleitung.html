Installieren

Windows

  1. Lade unter Download den Installer AnotherKeepass_<Version>_x64-setup.exe herunter.
  2. Starte ihn. Warnt Windows vor einem unbekannten Herausgeber, liegt das an der noch fehlenden Code-Signatur (siehe Wenn etwas hakt).
  3. Der Installer legt AnotherKeepass im Startmenü an. Die WebView2-Laufzeit ist bei Windows 11 schon vorhanden.

Linux (Vorschau)

  1. Lade die Datei .AppImage herunter.
  2. Mach sie ausführbar und starte sie:
chmod +x AnotherKeepass_*.AppImage
./AnotherKeepass_*.AppImage

Die Linux-Version baut, ist aber noch kaum getestet. Windows Hello und andere reine Windows-Optionen sind ausgeblendet; Auto-Type-Fenstererkennung, Browser-Manifeste und Sperren bei Bildschirmsperre fehlen noch.

Updates

Die App prüft in den Einstellungen wöchentlich, ob es eine neue Version auf GitHub gibt, und kann sie direkt installieren. Installiert wird ein Update nur, wenn es die Signatur des Projekts trägt (minisign, der öffentliche Schlüssel ist in die App eingebaut).

Releases baut GitHub Actions aus dem getaggten Quellcode. Was sich geändert hat, steht im Changelog.

Von 0.1.0 auf eine neuere Version: Mit 0.2.0 hat sich der Herausgeber geändert. Deinstalliere 0.1.0 deshalb einmal von Hand und lösche dabei die App-Daten nicht.

Erster Start

  1. Wähle Sprache und Design (hell oder dunkel). Beides lässt sich später in den Einstellungen ändern.
  2. Öffne eine vorhandene .kdbx-Datei oder lege einen neuen Tresor an. Optional gehört eine Schlüsseldatei dazu.
  3. Weitere Tresore öffnest du über Tresor hinzufügen in der Seitenleiste. Alle Tresore zeigt die Einträge aller offenen Tresore zusammen.

Tastenkürzel

  • Strg K – Befehlspalette: Einträge suchen, neue anlegen, Generator, Passwort-Gesundheit, Import.
  • Strg Alt K – Schnellzugriff von überall: Enter kopiert das Passwort, Umschalt+Enter den Benutzernamen, Strg+Enter tippt die Anmeldung. Das Kürzel lässt sich in den Einstellungen ändern.

Die Liste der zuletzt geöffneten Tresore merkt sich die App selbst, nicht die .kdbx-Dateien. Ist sie leer, öffne deine Tresore einmal über die Dateiauswahl.

Browser verbinden

AnotherKeepass stellt dieselbe lokale Verbindung bereit wie KeePassXC. Deshalb funktioniert die Erweiterung KeePassXC-Browser, inklusive Passkeys.

  1. Installiere KeePassXC-Browser in deinem Browser.
  2. Aktiviere in AnotherKeepass unter Einstellungen Browserintegration aktivieren und hake deine Browser an.
  3. Ist KeePassXC nicht installiert, schalte zusätzlich Native-Messaging-Manifeste beim Start aktualisieren ein. Dann meldet sich AnotherKeepass selbst als Proxy an. Ist KeePassXC installiert, läuft die Verbindung über dessen keepassxc-proxy.
  4. Verbinde die Erweiterung und bestätige die Anfrage in AnotherKeepass.

KeePassXC darf nicht gleichzeitig laufen – beide benutzen dieselbe Verbindung.

Von einem anderen Manager umziehen

Import

Öffne die Befehlspalette (Strg K) und wähle Importieren…. Unterstützt werden Exporte aus:

  • Bitwarden
  • 1Password
  • Proton Pass
  • KeePassXC (CSV)

Kommst du von KeePass, KeePassXC oder KeePassDX, brauchst du keinen Import: Öffne einfach deine .kdbx-Datei.

Vaultwarden

Über Tresor hinzufügen → Vaultwarden erscheint dein Vaultwarden-Konto als Tresor. Änderungen werden auf dem Server gespeichert; ohne Verbindung lässt sich die letzte Kopie lesen. Der Server muss per https erreichbar sein.

Mit Mit Vaultwarden abgleichen… hältst du eine .kdbx-Datei und ein Konto in beide Richtungen synchron; die neuere Änderung gewinnt.

SSH, KeeShare und Windows Hello

SSH-Agent

Unter Einstellungen SSH-Agent-Integration aktivieren. AnotherKeepass ist selbst kein Agent, sondern reicht die Schlüssel aus dem Tresor an einen laufenden Agent weiter – kompatibel mit KeeAgent.

KeeShare

Rechtsklick auf einen Ordner → Teilen. Als „Importieren“ oder „Synchronisieren“ geteilte Ordner werden aus ihrer Datei aktualisiert, sofern KeeShare-Import erlauben eingeschaltet ist.

Windows Hello

Mit Mit Windows Hello entsperren öffnest du einen gesperrten Tresor mit Gesicht, Fingerabdruck oder PIN statt mit dem Master-Passwort. Der Schlüssel bleibt im Speicher, bis du den Tresor schließt oder die App beendest.

Selbst bauen

Du brauchst Git, Node.js 24, Rust (stable) und die Voraussetzungen von Tauri – unter Windows die Visual Studio Build Tools mit „Desktopentwicklung mit C++“.

git clone https://github.com/bohannjein/AnotherKeepass.git
cd AnotherKeepass
npm ci
npm run dev                          # Vorschau im Browser mit Demo-Tresoren
npx tauri dev                        # Desktop-App mit echten .kdbx-Dateien
npx tauri build --bundles nsis       # Windows-Installer
npx tauri build --bundles appimage   # Linux

Wie der Code aufgebaut ist, erklärt ARCHITECTURE.md; wie du beitragen kannst, CONTRIBUTING.md.

Wenn etwas hakt

Windows warnt vor einem unbekannten Herausgeber

Die Windows-Version ist noch nicht code-signiert; die Signierung über die SignPath Foundation ist auf dem Weg. Bis dahin kann SmartScreen warnen.

Microsoft Defender meldet einen Trojaner

Defenders KI-Scanner hält frische, unsignierte Builds manchmal fälschlich für Schadsoftware. Lade die App nur von der offiziellen GitHub-Releaseseite. Trag keine pauschale Ausnahme im Defender ein.

Der Browser findet keine Einträge

Prüfe, ob KeePassXC noch läuft – dann beenden. Ohne installiertes KeePassXC muss Native-Messaging-Manifeste beim Start aktualisieren eingeschaltet sein.

Die Liste der Tresore ist leer

Öffne deine .kdbx-Dateien einmal über die Dateiauswahl. Die Dateien selbst sind davon nicht betroffen.

Noch offen?

Melde den Fehler auf GitHub – mit Version, Betriebssystem und den Schritten bis zum Fehler.
