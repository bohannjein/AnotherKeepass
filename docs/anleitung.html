Installieren

Windows

  1. Lade unter Download den Installer AnotherKeepass_<Version>_x64-setup.exe herunter.
  2. Starte ihn. Warnt Windows vor einem unbekannten Herausgeber, liegt das an der noch fehlenden Code-Signatur (siehe Wenn etwas hakt).
  3. Der Installer legt AnotherKeepass im Startmenü an. Die WebView2-Laufzeit ist bei Windows 11 schon vorhanden.

Linux (Vorschau)

Unter Download gibt es vier Varianten:

  • Debian, Ubuntu, Mint: die .deb-Datei herunterladen und doppelklicken. Die Software-Verwaltung installiert sie, danach steht AnotherKeepass im Startmenü. Im Terminal geht es mit sudo apt install ./AnotherKeepass_*.deb.
  • Fedora, openSUSE: genauso mit der .rpm-Datei, im Terminal sudo dnf install ./AnotherKeepass-*.rpm.
  • Flatpak (jede Distribution, auch Arch): flatpak install --user ./AnotherKeepass_*.flatpak oder Doppelklick. Läuft abgeschottet; die Browser-Verbindung und Auto-Type funktionieren in der Flatpak-Fassung noch nicht.
  • AppImage: ohne Installation. Ausführbar machen und starten:
chmod +x AnotherKeepass_*.AppImage
./AnotherKeepass_*.AppImage

Nur das AppImage aktualisiert sich selbst. Bei .deb, .rpm und Flatpak meldet die App eine neue Version, installiert wird sie über die neue Datei von der Download-Seite.

Die Linux-Version baut, ist aber noch kaum getestet. Windows Hello und andere reine Windows-Optionen sind ausgeblendet. Die Fenstererkennung für Auto-Type braucht xdotool und funktioniert nur unter X11, nicht unter Wayland. Das Sperren bei Bildschirmsperre nutzt dbus-monitor. Die Browser-Verbindung schreibt die Manifeste für Chrome, Chromium, Brave, Vivaldi, Edge und Firefox selbst.

Updates

Die App sucht beim Start und danach einmal am Tag nach einer neuen Version. Ein Update wird im Hintergrund geladen; im Menü erscheint dann neben dem Zahnrad ein Update-Knopf und unter dem Logo „Update … bereit“.

  • Per Klick: Update-Knopf oder Einstellungen → Installieren und neu starten.
  • Von allein: Mit Updates automatisch installieren (Standard) installiert die App das Update, sobald sie ungenutzt im Tray liegt: Fenster versteckt, alle Tresore gesperrt. Danach startet sie wieder im Tray.
  • Hinweis: Über neue Versionen benachrichtigen zeigt eine Meldung, sobald eine neue Version da ist. Sind beide Schalter aus, sucht die App nur noch, wenn du in den Einstellungen auf Jetzt nach Updates suchen klickst.
  • Beta-Versionen werden auf Wunsch gemeldet, aber nicht aus der App installiert; der Knopf öffnet die Release-Seite.

Installiert wird nur, was die Signatur des Projekts trägt (minisign, der öffentliche Schlüssel ist in die App eingebaut). Releases baut GitHub Actions aus dem getaggten Quellcode. Was sich geändert hat, steht im Changelog.

Ältere Versionen: Bis 0.2.2 ließ sich ein Update nicht zuverlässig aus der App installieren. Installiere 0.2.3 oder neuer deshalb einmal von Hand über den Installer; deine Tresore und Einstellungen bleiben erhalten. Wer noch 0.1.0 hat, deinstalliert sie vorher, weil sich mit 0.2.0 der Herausgeber geändert hat (App-Daten dabei nicht löschen).

Erster Start

  1. Wähle die Sprache, dann das Design (Dunkel, Hell oder OLED mit reinem Schwarz) und eines von acht Farbschemata. Alles lässt sich später in den Einstellungen ändern.
  2. Öffne eine vorhandene .kdbx-Datei oder lege einen neuen Tresor an. Optional gehört eine Schlüsseldatei dazu.
  3. Weitere Tresore öffnest du über Tresor hinzufügen in der Seitenleiste. Alle Tresore zeigt die Einträge aller offenen Tresore zusammen.

Tastenkürzel

  • Strg K – Befehlspalette: Einträge suchen, neue anlegen, Generator, Passwort-Gesundheit, Import, Design wechseln.
  • Strg F – in die Suche springen. ↑ ↓ wechseln den Eintrag.
  • Strg Alt K – Schnellzugriff von überall: Enter kopiert das Passwort, Umschalt+Enter den Benutzernamen, Strg+Enter tippt die Anmeldung. Das Kürzel lässt sich in den Einstellungen ändern.
  • F1 – Übersicht aller Kürzel. Die vollständige Liste steht auch auf der Startseite.

Die Liste der zuletzt geöffneten Tresore merkt sich die App selbst, nicht die .kdbx-Dateien. Ist sie leer, öffne deine Tresore einmal über die Dateiauswahl.

Oberfläche

Design und Farbschema

Unter Einstellungen → Darstellung: Dunkel, Hell oder OLED sowie die Farbschemata Terrakotta (Standard), Nord, Gruvbox, Solarized, Rosé Pine, Everforest, Tokyo Night und Dracula. Jedes Schema hat eine helle und eine dunkle Fassung; Buchstaben-Avatare, Tresorfarben und Warnfarben passen sich an. Eine Vorschau aller Kombinationen zeigt die Startseite.

Spalten

  • Menü, Eintragsliste und Detailansicht trennt je ein Griff. Er erscheint, wenn die Maus kurz auf der Spaltengrenze ruht; ziehen ändert die Breite.
  • Mit dem Griff im Fokus verschieben ← → die Grenze, ein Doppelklick stellt die Standardbreite wieder her.
  • Zieht man das Menü sehr schmal, klappt es zur Symbolleiste ein. Die Breiten werden gespeichert.

Suche

Die Suche durchsucht Titel, Tags, Benutzername, Website, Notizen und eigene Felder samt deren Namen. Mehrere Wörter müssen alle vorkommen, egal in welcher Reihenfolge. Passwörter, PINs und TOTP-Geheimnisse werden nie durchsucht.

Tray

Mit dem Tray-Symbol (Einstellungen → Darstellung) schließt das Fenster in den Infobereich, statt die App zu beenden; ein Klick auf das Symbol holt es zurück. Gesperrt wird das Symbol blasser. Beenden geht über Rechtsklick → Beenden.

Browser verbinden

AnotherKeepass stellt dieselbe lokale Verbindung bereit wie KeePassXC. Deshalb funktioniert die Erweiterung KeePassXC-Browser, inklusive Passkeys.

  1. Installiere KeePassXC-Browser in deinem Browser.
  2. Aktiviere in AnotherKeepass unter Einstellungen Browserintegration aktivieren und hake deine Browser an.
  3. Ist KeePassXC nicht installiert, schalte zusätzlich Native-Messaging-Manifeste beim Start aktualisieren ein. Dann meldet sich AnotherKeepass selbst als Proxy an. Ist KeePassXC installiert, läuft die Verbindung über dessen keepassxc-proxy.
  4. Verbinde die Erweiterung und bestätige die Anfrage in AnotherKeepass.

KeePassXC darf nicht gleichzeitig laufen – beide benutzen dieselbe Verbindung.

Von einem anderen Manager umziehen

Import

Öffne die Befehlspalette (Strg K) und wähle Importieren…. Unterstützt werden Exporte aus:

  • Bitwarden
  • 1Password
  • Proton Pass
  • KeePassXC (CSV)

Kommst du von KeePass, KeePassXC oder KeePassDX, brauchst du keinen Import: Öffne einfach deine .kdbx-Datei.

Vaultwarden

Über Tresor hinzufügen → Vaultwarden erscheint dein Vaultwarden-Konto als Tresor. Änderungen werden auf dem Server gespeichert; ohne Verbindung lässt sich die letzte Kopie lesen. Der Server muss per https erreichbar sein.

Mit Mit Vaultwarden abgleichen… hältst du eine .kdbx-Datei und ein Konto in beide Richtungen synchron; die neuere Änderung gewinnt.

SSH, KeeShare und Windows Hello

SSH-Agent

Unter Einstellungen SSH-Agent-Integration aktivieren. AnotherKeepass ist selbst kein Agent, sondern reicht die Schlüssel aus dem Tresor an einen laufenden Agent weiter – kompatibel mit KeeAgent.

KeeShare

Rechtsklick auf einen Ordner → Teilen. Als „Importieren“ oder „Synchronisieren“ geteilte Ordner werden aus ihrer Datei aktualisiert, sofern KeeShare-Import erlauben eingeschaltet ist.

Windows Hello

Mit Mit Windows Hello entsperren öffnest du einen gesperrten Tresor mit Gesicht, Fingerabdruck oder PIN statt mit dem Master-Passwort. Der Schlüssel bleibt im Speicher, bis du den Tresor schließt oder die App beendest.

Selbst bauen

Du brauchst Git, Node.js 24, Rust (stable) und die Voraussetzungen von Tauri – unter Windows die Visual Studio Build Tools mit „Desktopentwicklung mit C++“.

git clone https://github.com/johann-beinsen/AnotherKeepass.git
cd AnotherKeepass
npm ci
npm run dev                          # Vorschau im Browser mit Demo-Tresoren
npx tauri dev                        # Desktop-App mit echten .kdbx-Dateien
npx tauri build --bundles nsis       # Windows-Installer
npx tauri build --bundles appimage   # Linux

In der Browser-Vorschau erzeugt ?big=5000 an der Adresse einen zusätzlichen Demo-Tresor mit so vielen Einträgen, etwa um große Tresore zu testen. Wie der Code aufgebaut ist, erklärt ARCHITECTURE.md; wie du beitragen kannst, CONTRIBUTING.md.

Wenn etwas hakt

Windows warnt vor einem unbekannten Herausgeber

Die Windows-Version ist noch nicht code-signiert; die Signierung über die SignPath Foundation ist auf dem Weg. Bis dahin kann SmartScreen warnen.

Microsoft Defender meldet einen Trojaner

Defenders KI-Scanner hält frische, unsignierte Builds manchmal fälschlich für Schadsoftware. Lade die App nur von der offiziellen GitHub-Releaseseite. Trag keine pauschale Ausnahme im Defender ein.

Das Fenster bleibt weiß

Stürzt die Anzeige ab (etwa nach Standby oder einem Grafiktreiber-Update), lädt die App die Seite neu oder baut das Fenster neu auf und sperrt dabei die offenen Tresore. Bleibt das Fenster trotzdem weiß, beende die App über Rechtsklick auf das Tray-Symbol → Beenden und melde den Fehler mit der Log-Datei.

Der Browser findet keine Einträge

Prüfe, ob KeePassXC noch läuft – dann beenden. Ohne installiertes KeePassXC muss Native-Messaging-Manifeste beim Start aktualisieren eingeschaltet sein.

Die Liste der Tresore ist leer

Öffne deine .kdbx-Dateien einmal über die Dateiauswahl. Die Dateien selbst sind davon nicht betroffen.

Log-Datei

Die App schreibt nach %LOCALAPPDATA%\app.anotherkeepass.desktop\logs\anotherkeepass.log. Sie protokolliert Abläufe wie Start, Öffnen eines Tresors und Fehler, aber keine Passwörter. Schau sie trotzdem kurz durch, bevor du sie anhängst.

Noch offen?

Melde den Fehler auf GitHub – mit Version (steht unter dem Logo in der App), Betriebssystem und den Schritten bis zum Fehler.
