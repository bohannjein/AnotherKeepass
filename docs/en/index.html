AnotherKeepass

A password manager for Windows and Linux that reads and writes vaults in the KeePass format (KDBX 4). The files stay compatible with KeePassXC, KeePass2 and KeePassDX.

Download for WindowsInstaller, 64-bit Guide (German)

Free and open source (GPL-3.0) · Linux and other options

There is no app for phones. Your .kdbx file opens there in KeePassDX, for example.

Key facts

File format
KDBX 4 (read and write). KDBX 3.1 is read and upgraded to KDBX 4 on the first save; the original stays next to it as .kdbx3-backup.
Compatible with
KeePassXC, KeePass2, KeePassDX and every other program that opens KDBX 4
Platforms
Windows 10/11 (x64). Linux as an AppImage (preview). No macOS, no mobile app.
Account / cloud
Not needed. Vaults are files wherever you keep them. Optional: connect a Vaultwarden account.
Telemetry
None. Network access only for the update check, favicons, the optional breach check and Vaultwarden – each can be switched off.
Languages
English, German, French, Spanish
Technology
Tauri 2, Rust (vault logic), React (interface), WebView2 on Windows
License
GPL-3.0-or-later, source code on GitHub

Features

Vaults and entries

  • Several vaults open at once, search across all of them
  • Color and icon per vault
  • Folders (KeePass groups), tags, pinned entries
  • Entry types: login, card, identity, PIN, note, other, templates
  • Custom fields, attachments with preview, expiry date, history of earlier versions
  • TOTP one-time codes in KeePassXC's format
  • Recycle bin (KeePass recycle bin), multi-select to move and delete
  • Sort by last use, title, modified or created date; group by letter, type, folder, vault, domain, tag or date
  • Search across all plain-text fields, with operators like in KeePassXC: user:, url:, tag:, is:weak, is:expired, -exclude

Passwords

  • Generator for character strings and passphrases (EFF word list)
  • Strength meter with zxcvbn that takes the entry's own data into account
  • Password health: weak, reused, old and expired passwords
  • Optional: check against haveibeenpwned.com (k-anonymity, the password never leaves the computer)
  • The clipboard is cleared after a set time and stays out of the Windows clipboard history

Integrations

  • Browser through the KeePassXC-Browser extension, passkeys included
  • Open a Vaultwarden account as a vault or keep it in sync with a .kdbx
  • Import from Bitwarden, 1Password, Proton Pass and KeePassXC (CSV)
  • Hand SSH keys to the SSH agent (KeeAgent-compatible)
  • KeeShare to share folders through their own files
  • Auto-Type: type logins into other programs

Interface

  • 8 color schemes plus your own colors, each light, dark and OLED black; can follow the system (overview)
  • Drag the column widths; the menu folds into an icon rail
  • Command palette (Ctrl K) and global quick access
  • Tray icon, start with Windows, start minimized
  • Font size 80–150 %, compact list view

Themes

Eight color schemes, each with a light and a dark variant. OLED mode puts the dark variant on pure black, “System” switches between light and dark with Windows. You can also set your own background, text and accent colors. All under Settings → Appearance.

Security

Encryption
That of KDBX 4: AES-256 or ChaCha20, key derivation with Argon2 or AES-KDF. The app warns about weak derivation settings. Master password, optionally a key file and a YubiKey (challenge-response, compatible with KeePassXC).
Separation
The open vault lives in the Rust process. The interface only receives a password when you show, copy or edit it.
Locking
Locking overwrites keys and protected values in memory. Automatically on inactivity, screen lock or user switch (configurable).
Hardening
Other processes of the same user cannot read the app's memory. The browser and SSH connections are reachable only for your own user. Vaultwarden account data is protected with Windows DPAPI.
Never stored
The master password. For unlocking with Windows Hello, only a key stays in memory after locking, never on disk; closing a vault drops it.
Updates
Only packages signed by the project are installed. Releases are built by GitHub Actions from the tagged source.
Limits
Whatever is on screen is also in the interface's memory. The Windows version is not code-signed yet. There has been no external security audit yet.

Known issues

  • The installer is not code-signed yet, so Windows SmartScreen warns about an unknown publisher.
  • Microsoft Defender occasionally flags fresh, unsigned builds by mistake.
  • From 0.2.2 or older: update once by hand with the installer. After that, updates come from the app.
  • Updating from 0.1.0: uninstall once by hand and keep the app data.

Build it yourself

Requirements: Node.js, Rust and Tauri's dependencies.

git clone https://github.com/johann-beinsen/AnotherKeepass.git
cd AnotherKeepass && npm ci
npx tauri build
