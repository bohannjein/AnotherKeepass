Kurz gesagt

  • AnotherKeepass hat kein Konto, keinen eigenen Server und keine Telemetrie.
  • Deine Tresore sind Dateien auf deinem Gerät oder an einem Ort, den du wählst. Ich als Entwickler habe keinen Zugriff darauf.
  • Die App baut nur Verbindungen auf, die unten beschrieben sind. Fast alle davon lassen sich abschalten.

Die App

Was auf deinem Gerät gespeichert wird

  • Tresore (.kdbx): verschlüsselt mit deinem Master-Passwort und optional Schlüsseldatei oder YubiKey. Sie liegen dort, wo du sie speicherst.
  • Einstellungen und die Liste der zuletzt geöffneten Tresore: im Profil der App auf deinem Gerät.
  • Protokolldatei: Abläufe wie Start, Öffnen eines Tresors und Fehler, ohne Passwörter oder Eintragsinhalte. Sie verlässt dein Gerät nicht, außer du schickst sie selbst mit einer Fehlermeldung.
  • Windows Hello: Für das schnelle Entsperren bleibt ein Schlüssel nur im Arbeitsspeicher, nie auf der Festplatte.

Es werden keine Daten an mich oder an Dritte übertragen, die du nicht selbst auslöst.

Die Oberfläche läuft unter Windows in Microsoft Edge WebView2. Ob WebView2 Diagnosedaten an Microsoft sendet, richtet sich nach deinen Windows-Einstellungen zu Diagnosedaten, nicht nach AnotherKeepass.

Diese Website

  • Hosting: GitHub Pages (GitHub Inc., USA). GitHub verarbeitet beim Aufruf technisch nötige Daten wie deine IP-Adresse; siehe die Datenschutzerklärung von GitHub.
  • Versionsangabe: Die Seite fragt beim Laden die GitHub-API ab, um die neueste Version und die Download-Links anzuzeigen. Dabei sieht GitHub deine IP-Adresse.
  • Keine Cookies, keine Analyse, keine Werbung, keine fremden Schriften. Die Schrift wird von dieser Website selbst geladen.

Microsoft Store

Lädst du AnotherKeepass aus dem Microsoft Store, verarbeitet Microsoft die Daten zu Kauf, Download und Updates nach der Datenschutzerklärung von Microsoft. Ich erhalte darüber nur zusammengefasste Zahlen, etwa Anzahl der Installationen.
